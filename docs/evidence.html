Sources and reproduction

The presentation combines the published hardware study, supplied recordings and checkpoints, local CAD, and a separately documented Isaac Lab workbench. This page records their different scopes and the transformations used to make the figures.

The results CSV is a manual transcription of the per-chicken rows of Table 4 in Davar et al., Advanced Robotics Research (2026). A script checks the row sums and computes the displayed totals. It does not infer outcomes from video names or jaw commands.

Actual offline denoising replay

presentation/replay_denoising.py loads the supplied outputs/blah/checkpoints/latest.ckpt from checkpoint_dp.zip, selects the EMA weights, and runs the original policy class. Model weights load strictly, without missing or extra keys.

  • Recorded evaluation episode: 14; observations at elapsed 5.0, 12.0, and 20.0 seconds.
  • Two observations per input, three RGB cameras, end-effector pose, and both jaw states.
  • Random seed 42; 100 DDIM denoising iterations; horizon 16; trained action prefix length 6.
  • The scheduler records initial Gaussian noise and every prev_sample, yielding 101 arrays per observation. Values are exported both normalized and decoded into action units.
  • The three orientation dimensions are retained in the downloadable trace. The figures emphasize XYZ and the two jaw channels.

Interpretation: these are real model outputs from a new offline replay. They are not the original deployment predictions, and they were never sent to the robot. The source MP4s do not expose original camera wall-clock timestamps, so their elapsed time is matched approximately to each episode’s state timestamps. This is suitable for explaining the model, but is not an exact reconstruction of original inference conditions or a new success evaluation.

The final predicted sequence contains 16 positions in a temporal window. With two observation steps, the trained six-action prefix is indices 2–7 in one-based display indexing. The public runtime script overrides this setting; the offline replay preserves the checkpoint’s trained prefix length.

The interactive plot keeps normalized XYZ at a fixed scale unless “Zoom to plan” is selected. The revised static figure uses fixed axis limits; a separate final-action figure shows the physical units. All intermediate jaw values are retained in the data. The revised process video displays their full observed range.

Camera-overlay process video

The 10.93-second process video uses the supplied recording from episode 14, camera 2. At observations 5, 12, and 20 seconds, the footage pauses while six independently initialized candidates are denoised. The replay uses the public evaluation script’s overrides: 16 DDIM iterations and 15 returned future actions from a 16-step window. Every captured iteration is displayed for at least two frames. Color indicates future action index; the jaw inset displays raw values for candidate 1. Moving footage resumes at 4× speed.

These are actual new offline samples, not the original executed plans. The image overlay uses a local affine displacement estimate fitted from rigid gripper features and logged end-effector translation. The manually selected image anchor approximates the midpoint between the jaws. It is not a calibrated TCP location. No measured camera intrinsics or robot-to-camera transform were found.

The estimate was fit on alternating two-second blocks and evaluated on the withheld blocks: 1.76 px RMS, 4.11 px 95th-percentile tracking error. The fitted video-to-state offset is −0.28 s. These errors validate tracked local displacement only; they do not establish absolute projection accuracy. Noisy intermediate coordinates can extend beyond the fitted motion volume, so their projection is an extrapolation. The checkpoint inputs still use approximate elapsed-time alignment.

Individual action videos

Twenty diffusion-policy examples were selected by visible two-leg capture using wrist and side views. The unsuccessful example is DP episode 18. These are grasp-phase observations, not independently verified full-task outcome labels. The 23 videos preserve their original recorded endings.

The action overlays replay each method’s own checkpoint offline: DP uses six independent candidates and all 16 DDIM steps; IBC uses five rounds of 4,096 candidates, with 128 displayed per round; LSTM-GMM replays recurrent history and displays one-step samples, mixture means, and its selected action. IBC and LSTM-GMM displays are not denoising trajectories.

Per-episode image projections estimate local displacement from tracked gripper features, with a tracked origin at each observation. There is no measured camera calibration. Uncorrected held-out affine RMS errors range from 0.4 to 6.2 pixels; episode 57 has the largest error. These errors measure displacement fit, not absolute TCP accuracy. Displayed plans were not executed; playback resumes the original recording.

Reproduce and extend

Use the scripts in presentation/README.md. The exports preserve source filenames, checkpoint configuration, archive coverage, and hashes. The public repository base inspected was commit 321a566.

python presentation/analyze_sources.py --data-root /path/to/ChicGrasp-data
python presentation/build_figures.py
python -m http.server 8000 --directory docs

Offline GPU replay and CAD export require their respective model and OpenUSD environments. Viewing the page only requires a browser; the numerical explorer loads a local JavaScript data bundle and does not call a model service.
